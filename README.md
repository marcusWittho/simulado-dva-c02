# aws-estudo

Material de estudo para a certificação **AWS Certified Developer – Associate (DVA-C02)**.

## Conteúdo

- [Cronograma de estudos](https://htmlpreview.github.io/?https://github.com/marcusWittho/simulado-dva-c02/blob/main/cronograma-dva-c02.html) — plano semana a semana, com mapeamento para o AWS Developer Learning Plan, rotina semanal e marcos de controle.
- [Simulados](simulados/) — provas de treino por tema:
  - **IAM**
    - [Simulado IAM (v1)](https://htmlpreview.github.io/?https://github.com/marcusWittho/simulado-dva-c02/blob/main/simulados/01-IAM/simulado-iam-v1.html)
    - [Simulado IAM difícil (v2)](https://htmlpreview.github.io/?https://github.com/marcusWittho/simulado-dva-c02/blob/main/simulados/01-IAM/simulado-iam-v2.html)

## Como usar

1. Siga o cronograma e estude cada tema.
2. Faça o simulado correspondente ao tema ao final.
3. Revise os pontos errados antes de avançar.

Os links abrem as páginas renderizadas via [htmlpreview.github.io](https://htmlpreview.github.io/). Os arquivos precisam estar commitados e publicados na branch `main`.
